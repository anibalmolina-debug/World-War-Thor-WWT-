# G0 Visual Audit: WWII War-Cabinet Aesthetic
# Reference Sheet

## Palette
- Paper: #f4f1ea (aged manila, off-white)
- Ink: #2b2b2b (carbon black, slightly faded)
- Olive: #556b2f (dark olive green, military drab)
- Alarm: #b22222 (firebrick red, urgent alerts)
- Phosphor: #33ff33 (vintage CRT green, monochrome display)

## Typography
- Primary: Courier New, Courier, monospace (typewriter style)
- Accents: Georgia, serif (official documents)

## Spacing & Layout
- Grid: Rigid, tabular, aligned to margins
- Borders: Single line, double line (official forms)
- Effects: Slight bleed, CRT scanlines, paper texture
