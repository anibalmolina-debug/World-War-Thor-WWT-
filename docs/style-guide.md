# Style guide (G0, recreated — not copied)

Mood: WWII war-cabinet bunker, typed dossiers, stamped paper, CRT ticker,
classified folder on an olive blotting-paper desk.

Do:

- Semantic elements, classes (`c-`, `l-`, `s-`), `data-*` for state
- Paper cream on olive grid; alarm red only for stamps and primary duty
- Tabular numbers on plates; typewriter for readouts
- Reduced-motion: freeze radar and ticker typing

Don't:

- Inline styles from JS/C++
- CSS frameworks
- Emoji as the only glyph
- Copy original-site CSS, fonts, images, or Player Guide text
